# Broad-universe backtest: generated tables

Generated by `scripts/backtest_broad_universe.py`; do not edit by hand. The written report with verdicts is `docs/backtest-broad-universe.md`.

Returns are close to close over 20 and 60 trading days after the signal day. Win = share of days with a positive forward return. Excess = forward return minus the same-day mean of the whole universe, which removes the market's move. Vol-matched excess = forward return minus the same-day mean of stocks in the same volatility quintile (ATR/close), which also removes the reward for simply holding more volatile stocks. 95% intervals come from a bootstrap over calendar quarters.
